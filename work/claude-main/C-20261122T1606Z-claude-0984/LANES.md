## 1. Frozen interface (both lanes build to this)

### `src/findsee/types.py` — `Preset` (frozen dataclass)

| Field | Type | Allowed values | Meaning |
|---|---|---|---|
| `name` | `str` | non-empty | preset key |
| `zoom` | `float` | `>= 1.0` | centre crop of `1/zoom` of each side, then bicubic upscale back to the input size |
| `denoise` | `str` | `"none"`, `"median"`, `"bilateral"`, `"nlm"` | denoiser applied after the crop |
| `clahe_clip` | `float` | `> 0` | CLAHE clip limit on the Lab L channel |
| `clahe_tile` | `int` | `>= 1` | CLAHE tile grid size (tile x tile) |
| `sharpen_amount` | `float` | `>= 0` | unsharp-mask amount (0 = off) |
| `display` | `str` | `"plain"`, `"binary_dark"`, `"color_precomp"` | final display mode |
| `blue_gain` | `float` | `>= 1.0` | blue-channel gain, used only by `color_precomp` |

Invalid values raise `ValueError` in `__post_init__`. Equality and hashing are the dataclass defaults.

### `src/findsee/mode2/presets.py`

- `PRESETS: dict[str, Preset]` with exactly the keys `"cataract"` and `"amd"`; each value's `name` equals its key.
- `get_preset(name: str) -> Preset`; an unknown name raises `KeyError`.
- Draft values (not evaluated; tuning is a later stage):
  `cataract`: zoom 2.0, bilateral, clip 3.0, tile 8, sharpen 1.0, `color_precomp`, blue_gain 1.3;
  `amd`: zoom 3.0, median, clip 2.0, tile 8, sharpen 1.5, `binary_dark`, blue_gain 1.0.

### `src/findsee/mode2/pipeline.py` — `enhance(image, preset) -> np.ndarray`

- `image`: `np.ndarray`, BGR, `dtype uint8`, shape `(H, W, 3)`, `H, W >= 8`. Anything else raises `ValueError`
  (wrong dtype, wrong ndim, channel count != 3, too small).
- `preset`: a `Preset` or a preset name `str` (looked up with `get_preset`, so an unknown name raises `KeyError`).
- Returns a **new** array, `uint8`, shape **equal to the input shape** (display size = input size). The input is never
  modified. Deterministic: the same input and preset give a byte-identical output. No I/O, no logging above DEBUG.
- Order (review H5): crop (zoom) -> denoise -> CLAHE on Lab L -> bicubic upscale to input size -> unsharp mask ->
  display.
- `zoom == 1.0` skips the crop and the upscale.
- Display modes:
  - `plain`: the BGR result of the steps above.
  - `binary_dark`: grayscale -> adaptive threshold -> dark text becomes **yellow `(0, 255, 255)` on black
    `(0, 0, 0)`**; every output pixel is exactly one of those two colours.
  - `color_precomp`: the `plain` result with channel 0 (blue) multiplied by `blue_gain`, rounded and clipped to 255;
    channels 1 and 2 are **identical** to the `plain` result. Hence, for the same input and a preset that differs
    only in `display`, `out_precomp[..., 0] >= out_plain[..., 0]` elementwise.

### Frozen interface, round 2

`src/findsee/mode2/presets.py` gains:

- `make_custom(base, *, zoom=None, clahe_clip=None, sharpen_amount=None, display=None, name="custom") -> Preset`:
  `base` is a `Preset` or a preset name (unknown name -> `KeyError`). Returns a NEW `Preset` equal to `base` with each
  non-`None` override applied and `name` set; every other field is copied from `base`. Invalid values raise
  `ValueError` (through `Preset` validation). `base` and `PRESETS` are never changed; the result is not registered.
  This is what the demo's sliders (zoom, contrast, sharpen, display) call.

New `src/findsee/mode2/live.py`:

- `class FpsMeter(window: int = 30, clock: Callable[[], float] = time.perf_counter)`: `window < 2` -> `ValueError`.
  `tick() -> None` records `clock()`; only the newest `window` ticks are kept. `fps() -> float | None`: with `n >= 2`
  kept ticks, `(n - 1) / (t_newest - t_oldest)`; `None` with fewer than 2 ticks or when that span is `<= 0`.
- `draw_status(frame, text) -> np.ndarray`: `frame` validated exactly like `enhance`'s input (`ValueError`); `text` is
  a `str` of printable ASCII (`0x20-0x7E`) or `ValueError` (OpenCV's Hershey fonts cannot draw Chinese; the app shows
  Chinese text in the UI, not on the frame). Returns a NEW `uint8` array of the same shape with the text drawn at the
  top-left on a filled black box; the input is never modified. An empty string returns an unchanged copy.
- `open_camera(index=0, width=1280, height=720) -> tuple[cv2.VideoCapture, tuple[int, int]]`: creates
  `cv2.VideoCapture(index)`, requests the size with `CAP_PROP_FRAME_WIDTH` / `CAP_PROP_FRAME_HEIGHT`, and returns the
  capture and the EFFECTIVE `(width, height)` read back with `get()` as ints (CLAUDE.md rule 8: report requested and
  effective). If `isOpened()` is false it calls `release()` and raises `RuntimeError` naming the index. No fallback to
  another camera.
- `run_live(camera_index=0, preset="cataract", width=1280, height=720) -> None`: interactive loop (camera + window);
  keys `q`/Esc quit, `1` cataract, `2` amd, `0` raw frame; overlays preset name and fps with `draw_status`; never
  writes frames to disk; logs requested and effective size at INFO. Not unit-tested (needs a camera and a display).

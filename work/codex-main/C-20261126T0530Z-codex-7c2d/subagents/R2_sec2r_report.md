## Deliberate exclusions and decision

- Preserve all slider field domains, validation of explicitly supplied names including `None`, and the distinct semantics of the four `None` slider sentinels. Preserve the fresh return even when equal to the base, keyword-only overrides, exact string lookup with `KeyError` on unknown names, and base and registry integrity even when the requested result name collides with a registry key (test_custom_preset.py:336-385).
- Preserve the default meter window and clock, the below-minimum integer error, tick retention, the formula and recovery, `None` for zero and negative spans, and no clock reads from `fps()`.
- Preserve complete frame and text validation, including wrong Python types and invalid frames with empty text. Preserve independent storage, same shape and dtype, unchanged pixels for empty text, a filled black box at the top-left, visible rendered glyphs, and acceptance of spaces.
- Preserve camera defaults and explicit positional and keyword arguments, one capture, no fallback, both property requests, successful capture ownership, effective readback as Python ints, and `RuntimeError` including the index after exactly one failure release.
- Preserve live defaults, the stated key actions, the preset name and fps overlay, in-memory frames, and INFO reporting of both sizes. Section 2R's live requirements hold independently of the absence of a camera/window unit test.

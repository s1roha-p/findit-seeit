## What and why
The repository starts with its rules and coordination files so several people and several coding agents (Claude Code,
Codex, Gemini) can work in parallel from the first week: the four parts and their interfaces, the evaluation protocol
that decides what may go on a slide, the data policy, and an advisor and research-advisor structure for reviews.

The guard's main design points:
1. Git commands never get refused for being git: every git rule produces a confirmation (R6), collected and raised only
   after every other check has passed, so a line that also breaks a non-git rule is still denied.
2. Gemini is a MAIN agent like Claude and Codex: `GEMINI.md` asks like `CLAUDE.md` / `AGENTS.md`, `.gemini/` is a
   harness folder like `.claude/`, `work/gemini-main/` is a MAIN session folder.
3. Python runs in conda `findsee` or a `.venv` inside the project.
4. `data/` writes ask (privacy); model weights and media files are never hand-written.
